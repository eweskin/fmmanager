# Fox File Manager (FoxFM) — документация

## 1. Назначение

**Fox File Manager** — консольный двухпанельный файловый менеджер для Windows,
написанный на C++ с использованием Win32 API (в стиле Norton Commander /
Total Commander / Midnight Commander). Программа целиком работает в текстовом
режиме консоли, но рисует псевдографический интерфейс с 24-битным цветом,
несколькими цветовыми темами, встроенным просмотрщиком файлов с подсветкой
синтаксиса и возможностью скачивать файлы по HTTP/FTP.

Исходный файл — один модуль `fm.cpp` (≈1820 строк), без внешних зависимостей,
кроме системных библиотек Windows.

---

## 2. Сборка и требования

### Платформа
- Только **Windows** (используются Win32-консоль, WinINet, ShellExecute и т. д.).
- Консоль должна поддерживать виртуальные терминальные последовательности
  (Windows 10 и новее — поддерживаются по умолчанию).

### Подключаемые библиотеки
В коде объявлены через `#pragma comment(lib, ...)`:
- `wininet.lib` — загрузка файлов по HTTP/FTP;
- `shlwapi.lib`;
- `shell32.lib` — открытие файлов сторонними приложениями (`ShellExecuteW`).

### Точка входа
Программа использует `wmain()` (Unicode-вариант), поэтому весь ввод/вывод
ведётся в широких символах (`wchar_t`, UTF-16).

### Пример сборки
```
cl /EHsc /utf-8 fm.cpp
```
или с MinGW:
```
g++ -municode -O2 fm.cpp -lwininet -lshlwapi -lshell32 -o fm.exe
```

## 3. Запуск и общий вид экрана

При старте программа:
1. Переключает консоль в альтернативный экранный буфер (`\x1b[?1049h`), скрывает
   курсор, включает обработку ANSI-последовательностей.
2. Загружает сохранённую тему из конфигурационного файла.
3. Открывает обе панели в текущем рабочем каталоге.
4. Показывает заставку (splash) с ASCII-артом, затем основной интерфейс.

Экран разделён на области:

```
┌─ Верхняя строка: имя программы, часы, тема [F9], помощь [F12] ─┐
│ ╭─ Панель 0 (левая) ─╮     ╭─ Панель 1 (правая) ─╮            │
│ │ Name  Size Created │     │ Name  Size Created  │            │
│ │ ▸ folder\          │     │   file.txt          │            │
│ │   ...              │     │   ...               │            │
│ ╰────────────────────╯     ╰─────────────────────╯            │
├─ Инфо-строка: количество выделенных элементов ────────────────┤
└─ Статус-строка: краткая подсказка по клавишам ────────────────┘
```

Активная панель выделяется акцентным цветом рамки и маркером «●» (неактивная —
«○»). Курсор в активной панели обозначается «▸», выделенные элементы — «◆».

## 4. Управление (горячие клавиши)

| Клавиша            | Действие                                                        |
|--------------------|-----------------------------------------------------------------|
| `↑` / `↓`          | Перемещение курсора (с ускорением при удержании)               |
| `Tab` / `←` / `→`  | Переключение между левой и правой панелями                      |
| `Enter`            | Войти в папку или открыть файл в просмотрщике                   |
| `Backspace`        | Перейти в родительский каталог                                  |
| `Home` / `End`     | К первому / последнему элементу                                 |
| `PgUp` / `PgDn`    | Прокрутка на страницу                                           |
| `Space` / `Insert` | Выделить / снять выделение (мультивыбор, в т. ч. между папками) |
| `F1`               | Копировать все выделенные элементы в активную панель            |
| `F2`               | Переместить (вырезать) все выделенные элементы в активную панель|
| `Del` / `F8`       | Удалить выделенные (или элемент под курсором, если ничего не выделено) |
| `F3`               | Просмотр содержимого файла (с подсветкой синтаксиса)            |
| `F4`               | Переключить детальный / краткий вид списка (для каждой панели)  |
| `F5`               | Скачать файл по HTTP-ссылке в текущий каталог                   |
| `F6`               | Скачать файл по FTP-ссылке                                      |
| `F7`               | Создать новую папку                                             |
| `F9`               | Открыть настройки темы                                          |
| `F12`              | Экран справки                                                   |
| `Esc` / `F10`      | Выход (или закрытие наложенного окна)                          |

## 5. Возможности

### 5.1. Навигация по файловой системе
Каждая панель (`Panel`) хранит текущий путь, список элементов, позицию курсора
и положение прокрутки. Содержимое каталога загружается функцией `loadDir()`:
- сначала добавляется элемент `..` (если это не корень диска);
- каталоги и файлы перечисляются через `FindFirstFileW`/`FindNextFileW`;
- они сортируются по имени без учёта регистра, причём **папки идут раньше файлов**.

### 5.2. Два режима отображения списка
Клавиша `F4` переключает панель между:
- **кратким** видом — только имена;
- **детальным** видом — имя, размер, дата создания и дата изменения.

Размеры форматируются в B/K/M/G (`fmtSize`), даты — в формате `ДД.ММ.ГГГГ`
с переводом во локальное время (`fmtDate`).

### 5.3. Выделение и операции с файлами
Выделение (`Space`) работает как мультивыбор и сохраняется **глобально** —
можно отметить элементы в разных каталогах, а затем выполнить операцию.
Список отметок хранится в `g_marks` (вектор `MarkItem` с полным путём и флагом
«это папка»).

Операции:
- **Копирование** (`F1`) — рекурсивно через `copyRecursive()` (`CopyFileW` для
  файлов, обход дерева для папок).
- **Перемещение** (`F2`) — сначала пытается `MoveFileExW`; если не удалось
  (например, между дисками), выполняет копирование + удаление оригинала.
- **Удаление** (`Del`/`F8`) — рекурсивно через `deleteRecursive()` с
  подтверждением (диалог «Y/N»); снимает атрибуты «только чтение» перед удалением.
- **Создание папки** (`F7`) — запрашивает имя и вызывает `CreateDirectoryW`.

Все операции показывают прогресс и итог в статус-строке, при ошибках выводят
системное сообщение об ошибке (`winErr` через `FormatMessageW`).

### 5.4. Просмотрщик файлов с подсветкой синтаксиса
Открытие файла (`Enter` или `F3`) вызывает `viewFile()`:
- читается до **64 МБ** содержимого (больше — обрезается с пометкой `[TRUNCATED]`);
- определяется кодировка: распознаются BOM UTF-16LE и UTF-8, при ошибках
  декодирования UTF-8 происходит откат на системную ANSI-кодовую страницу;
- **бинарные файлы** определяются эвристикой (`isBinaryData`) — при их обнаружении
  показывается окно с предложением открыть файл системным приложением
  (`ShellExecuteW`);
- по расширению подбирается язык (`langFor`) и применяется подсветка
  (`highlight`).

Поддерживается подсветка для языков семейства C/C++/C#, JavaScript/TypeScript,
Java, Go, Rust, PHP, Swift, Kotlin, Python, шелл-скриптов, YAML/INI/TOML,
Lua, SQL и т. д. Подсвечиваются ключевые слова, типы, строки (в т. ч. тройные
для Python), числа, комментарии (строчные и блочные), препроцессор `#...`,
имена функций (идентификатор перед `(`) и операторы.

В просмотрщике доступны прокрутка по вертикали и горизонтали, переход в начало/конец,
номера строк. Выход — `Esc` или `F3`.

### 5.5. Загрузка по HTTP/FTP
Клавиши `F5` (HTTP) и `F6` (FTP) запрашивают URL и скачивают файл в текущий
каталог активной панели через WinINet (`InternetOpenUrlW` + `InternetReadFile`).
Имя файла извлекается из URL и очищается от недопустимых символов
(`sanitizeFileName`).

### 5.6. Цветовые темы
Доступно множество встроенных тем (`g_themes`): *Default, Midnight, Matrix,
Dracula, Paper, Black, Snow, Mono, Solar Dark, Solar Light, Nord, Gruvbox,
Tokyo Night, Monokai*. Тема **Mono** дополнительно позволяет выбрать акцентный
цвет из палитры оттенков (`g_monoHues`).

Настройки открываются по `F9` (`settingsScreen`): стрелками выбирается тема,
`←`/`→` — акцент для Mono, `Enter` — применить и сохранить, `Esc` — отмена.
Выбранная тема **сохраняется между запусками** в файле:
```
%LOCALAPPDATA%\FoxFM\theme.txt
```
(формат: два числа — индекс темы и индекс акцентного оттенка).

### 5.7. Заставка и справка
- **Splash-экран** (`splashScreen`) масштабирует встроенный ASCII-арт под размер
  окна и анонимирует его построчно; нажатие любой клавиши пропускает анимацию.
- **Экран справки** (`F12`) выводит таблицу горячих клавиш.

## 6. Архитектура кода

Файл логически разбит на секции (отмечены комментариями-разделителями):

| Секция                              | Содержание |
|-------------------------------------|------------|
| Data structures & global state      | Структуры `Entry`, `Panel`, `MarkItem`; глобальное состояние, отметки, ускорение курсора (`accelStep`) |
| Color indices & attributes          | Перечисление индексов цветов `CI_*`, макрос `ATTR`, предвычисленные атрибуты `A_*` |
| Themes & palettes                   | Таблица тем `g_themes`, оттенки Mono, активная палитра `g_activePal` |
| Console buffer & render primitives  | Двойная буферизация: `queryConsole`, `putCh`, `putStr`, `fillRow`, `drawBox`, и `flush` (вывод буфера ANSI-последовательностями с truecolor) |
| Palette / theme apply & persistence | `buildPalette`, `applyTheme`, `saveTheme`, `loadTheme`, `cfgPath` |
| Path & string helpers               | `joinPath`, `baseName`, `parentDir`, `isDriveRoot`, `winErr`, `sanitizeFileName` |
| Directory listing & formatting      | `loadDir`, `fmtSize`, `fmtDate`, `shortPath` |
| UI rendering                        | `renderPanel`, `drawTopBar`, `drawInfoBar`, `renderStatus`, `render` |
| Settings / Help / Splash            | `settingsScreen`, `helpScreen`, `splashScreen`, ASCII-арт |
| File operations                     | `copyRecursive`, `deleteRecursive` |
| Prompts & dialogs                   | `promptLine`, `confirmYesNo` |
| Download                            | `downloadUrl`, `doDownload` |
| Syntax highlighting                 | таблицы ключевых слов/типов, `langFor`, `highlight` |
| File viewer                         | `isBinaryData`, `blockedScreen`, `viewFile` |
| File-op actions & navigation        | `doPaste`, `doDelete`, `doMkdir`, `enterEntry` |
| Entry point & main loop             | `wmain` — инициализация, главный цикл обработки ввода |

### Принцип отрисовки
Программа держит экранный буфер `g_buf` (массив `CHAR_INFO` размером экрана).
Все примитивы рисуют в этот буфер, а `flush()` единым проходом превращает его
в строку ANSI-последовательностей (24-битные цвета `\x1b[38;2;r;g;bm`) и
выводит через `WriteConsoleW`. Это устраняет мерцание. Флаг `g_needClear`
заставляет очистить экран при изменении размера окна или темы.

### Главный цикл
`wmain` в цикле: опрашивает размер консоли, отрисовывает экран, читает события
ввода (`ReadConsoleInputW`) и по коду виртуальной клавиши вызывает нужное
действие. При выходе восстанавливает курсор и основной экранный буфер консоли.

## 7. Хранение данных и состояние

- **Конфигурация темы:** `%LOCALAPPDATA%\FoxFM\theme.txt`.
- **Выделенные элементы** (`g_marks`) живут только в течение сеанса.
- Никаких других файлов на диск программа не пишет, кроме результатов
  операций пользователя (копий, скачанных файлов, созданных папок).

---

## 8. Ограничения и замечания

- Работает только под Windows; требует консоль с поддержкой ANSI truecolor.
- Просмотрщик читает в память до 64 МБ файла; большие файлы обрезаются.
- Удаление выполняется **безвозвратно** (минуя «Корзину»), хотя и с
  подтверждением — следует быть внимательным.
- Минимальный поддерживаемый размер окна ограничен (40×10), при меньшем
  значения подгоняются.
- Подсветка синтаксиса — упрощённая (на основе расширения файла и набора
  ключевых слов), не является полноценным парсером.
